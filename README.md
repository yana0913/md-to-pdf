# 纸间 · Markdown 双栏排版

一个无需后端的 Markdown 排版工具。上传 `.md` 文件后，可实时预览并导出为：

- A4 纵向页面
- 双栏正文
- 上下左右 3cm 页边距
- 宋体正文
- 自动页码



## 导出 PDF

点击页面中的“导出 PDF”，在浏览器打印窗口中：

1. 目标打印机选择“另存为 PDF”；
2. 纸张选择 A4；
3. 缩放设为 100%；
4. 关闭浏览器自带的“页眉和页脚”；
5. 保存。

## 部署到 GitHub Pages

将本目录推送到 GitHub 仓库，在仓库的 **Settings → Pages** 中，将部署来源设为当前分支的根目录即可。项目为纯静态文件，不需要构建命令。

所有 Markdown 内容都只在浏览器本地处理，不会上传到服务器。
